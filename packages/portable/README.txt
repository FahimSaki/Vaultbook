VAULTBOOK (portable)
1. Start: double-click start.bat (Windows) or run start.sh (Linux or Mac).
2. First time only: choose a long password (12+ characters). Write the
recovery code on paper and keep it safe. It is shown once.
3. When you are done, close the browser window. Vaultbook locks itself
and exits.
4. Never pull the USB stick out while the black window is still open.
5. Back up: copy the whole data folder to another stick regularly.
6. Update: replace the app and launcher folders; keep the data folder.
7. If Windows or your antivirus asks about the script, that is because it
is not digitally signed. It only starts the program in this folder.
8. No internet is used. Nothing is sent anywhere.
9. Forgot the password? Use the recovery code on the unlock screen.
Lost both? The data cannot be recovered. That is by design
